# rent-watch

白天（日本时间 8–22 点）每 20 分钟、夜里每小时查一次 SUUMO / HOME'S，现住处开车约 10 分钟范围内、以及湘南台駅徒歩 15〜25 分或巴士 5 分以内、海老名駅徒歩 20 分以内的范围内出现符合条件的新房源、降价、重新招租时，用 ntfy（免费）推送到手机。

- 条件、范围（町名列表 `towns`、车站步行圈 `stations`）在 `config.json` 里改，push 后下一次运行生效。
- `state.json` 是已见过的房源记录，由 Actions 自动提交，不要手动改。删掉它会重新发一次"现有房源一览"。
- 通知：GitHub Secrets 里设 `NTFY_TOPIC`（手机 ntfy App 订阅同名频道）。另外设了 `WXPUSHER_TOKEN`/`WXPUSHER_UID` 的话也会同时发到微信。
- 本地试跑：`npm ci` 后 `node watch.mjs --dry-run`（只打印，不推送）。
- SUUMO 详情页的「情報更新日」变了也会推送（写明改了什么；内容没变的例行刷新用低优先级静默推送）。每间每天最多查一次详情页。
- 筑年数超过 15 年的，SUUMO 详情页写明 5 年内翻新过（或写了リノベーション・内装リフォーム済等）也会推送，标「新房源（翻新）」。翻新判断结果缓存 7 天。
- at home：每 3 小时一次，只看各市 2LDK/3LDK 新着顺第 1 页，请求间隔 3 秒；遇到验证页就跳过这一轮（不绕过）。HOME'S 在 GitHub 上一直被拦，已关闭。
- 停车费从 SUUMO 详情页读取。HOME'S 的详情页有反爬验证读不到，只在 HOME'S 上有的房源会标"停车费请点开确认"。
- 某个网站连续失败（SUUMO 3 次 / HOME'S 24 次）会推送一条出错通知。
